# Безопасность и приватные данные

Этот репозиторий публичный. Любой текст, изображение, Issue или комментарий может быть прочитан и сохранён посторонними.

## Не публикуйте

- приватные ключи AWG;
- UUID, пароли и токены профилей;
- полные рабочие URI;
- URL подписок с персональным токеном;
- резервные копии SG Mobile;
- QR-коды рабочих конфигураций;
- адреса внутренних серверов;
- необработанные журналы;
- скриншоты с личными уведомлениями и именами учётных записей.

Частичное закрашивание строки не всегда безопасно. Для публичного примера лучше заменить всё значение демонстрационными данными.

## Как подготовить отчёт

Укажите:

1. модель телефона;
2. версию Android и оболочки;
3. версию SG Mobile и versionCode;
4. протокол и используемое ядро;
5. тип сети: Wi-Fi, LTE или 5G;
6. точные шаги воспроизведения;
7. ожидаемый результат;
8. фактический результат;
9. время события;
10. очищенный фрагмент журнала.

Для демонстрации используйте условные названия, например `Demo Europe`, `Singapore 01` или `AWG 3.1 Test`.

## Сообщение об уязвимости

Не размещайте технические подробности уязвимости и рабочие секреты в публичном Issue.

Создайте краткий Issue без конфиденциальных данных и укажите, что требуется закрытый канал связи. Не прикладывайте эксплойт, ключи, токены, рабочий профиль или резервную копию до согласования безопасного способа передачи.

## Проверка APK

Устанавливайте APK только из официального GitHub Release этого репозитория. В одном релизе должны находиться APK и соответствующая контрольная сумма SHA-256.

Несовпадение SHA-256 означает, что файл повреждён либо изменён. Такой APK устанавливать нельзя.
