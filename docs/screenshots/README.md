# Скриншоты SG Mobile

В этом каталоге публикуются скриншоты актуального интерфейса SG Mobile.

## Публикация

В репозитории находятся исходные PNG в разрешении **1080 × 2340**. Файлы не уменьшаются и не перекодируются перед публикацией.

На главной странице README эти же оригиналы отображаются с уменьшенной визуальной шириной через HTML. По нажатию открывается полный PNG.

## Основной набор снимков

1. `01-home-disconnected.png` — главный экран, VPN отключён.
2. `02-home-connected.png` — главный экран, VPN подключён.
3. `03-profiles.png` — список нод и результаты проверки.
4. `04-import-profile.png` — импорт ссылки, файла или QR-кода.
5. `05-subscriptions.png` — список подписок.
6. `06-subscription-nodes.png` — ноды, протоколы и доступность.
7. `07-traffic-15min.png` — график трафика за последние 15 минут.
8. `07-traffic-statistics.png` — общая статистика трафика.
9. `08-routing.png` — VPN, Direct, Block и правила.
10. `09-per-app.png` — VPN для приложений.
11. `10-leak-protection.png` — IPv4, IPv6, DNS и системная защита.
12. `10-settings-battery-autorotate.png` — автоповорот и экономия батареи.
13. `11-backup.png` — резервная копия и восстановление.
14. `12-diagnostics.png` — журнал и диагностика.

## Требования к новым снимкам

- один телефон и одинаковое разрешение;
- вертикальная ориентация;
- русский язык;
- одинаковая тема и масштаб интерфейса;
- исходный PNG без предварительного уменьшения;
- текст должен полностью помещаться на экране;
- отсутствие ключей, токенов, паролей, UUID и других действующих секретов;
- отсутствие личных уведомлений в строке состояния.

Разовые тестовые адреса допустимы, если они больше не используются и их публикация явно подтверждена владельцем проекта.

Для основной галереи используется светлая тема. Несколько ключевых экранов в тёмной теме можно добавить отдельным дополнительным набором.
