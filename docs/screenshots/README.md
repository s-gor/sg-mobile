# Скриншоты SG Mobile

В этом каталоге публикуются только обезличенные скриншоты актуального интерфейса.

## Основной набор

1. `01-home-disconnected.png` — главный экран, VPN отключён.
2. `02-home-connected.png` — главный экран, VPN подключён.
3. `03-profiles.png` — список профилей.
4. `04-import-profile.png` — импорт ссылки, файла или QR-кода.
5. `05-subscriptions.png` — список подписок.
6. `06-subscription-nodes.png` — ноды, фильтры и выбор.
7. `07-status.png` — скорость, трафик и маршруты.
8. `08-routing.png` — VPN, Direct, Block и правила.
9. `09-per-app.png` — VPN для приложений.
10. `10-leak-protection.png` — IPv4, IPv6, DNS и системная защита.
11. `11-backup.png` — резервная копия и восстановление.
12. `12-diagnostics.png` — журнал и диагностика.

## Требования

- один телефон и одинаковое разрешение;
- вертикальная ориентация;
- русский язык;
- одинаковая тема и масштаб интерфейса;
- исходный PNG без предварительного уменьшения;
- демонстрационные названия профилей и серверов;
- отсутствие приватных URL, UUID, ключей, токенов и внутренних адресов;
- отсутствие личных уведомлений в строке состояния;
- текст должен полностью помещаться на экране.

Для основной галереи используется светлая тема. Несколько ключевых экранов в тёмной теме можно добавить отдельным дополнительным набором.
