# Скриншоты SG Mobile

В этом каталоге публикуются только обезличенные снимки актуального интерфейса.

## Опубликованная галерея

Для главной страницы подготовлены три оптимизированных WebP-коллажа:

1. `gallery-01-main.webp` — главный экран в отключённом и подключённом состояниях, импорт профиля и статистика трафика.
2. `gallery-02-network.webp` — график за последние 15 минут, маршрутизация, VPN для приложений и защита от утечек.
3. `gallery-03-tools.webp` — автоповорот и экономия батареи, резервная копия, диагностика и место под профили с подписками.

Исходные снимки получены через ADB в формате PNG с разрешением 1080 × 2340. Для README используются уменьшенные WebP-копии, чтобы главная страница загружалась быстрее.

## Кадры, требующие пересъёмки

Следующие исходные снимки не публикуются:

- `03-profiles.png`;
- `05-subscriptions.png`;
- `06-subscription-nodes.png`.

На них видны рабочие адреса серверов или источников подписок. Простое размытие и закрашивание не используется: такие кадры необходимо переснять с демонстрационными данными.

Для новых снимков используйте:

- нейтральные названия профилей и подписок;
- домены вида `example.invalid`;
- демонстрационные IP-адреса из документальных диапазонов;
- отсутствие UUID, ключей, токенов и приватных URL.

## Основной набор

1. `01-home-disconnected.png` — главный экран, VPN отключён.
2. `02-home-connected.png` — главный экран, VPN подключён.
3. `03-profiles.png` — список профилей.
4. `04-import-profile.png` — импорт ссылки, файла или QR-кода.
5. `05-subscriptions.png` — список подписок.
6. `06-subscription-nodes.png` — ноды, фильтры и выбор.
7. `07-traffic-15min.png` — график трафика за последние 15 минут.
8. `07-traffic-statistics.png` — статистика трафика.
9. `08-routing.png` — VPN, Direct, Block и правила.
10. `09-per-app.png` — VPN для приложений.
11. `10-leak-protection.png` — IPv4, IPv6, DNS и системная защита.

13. `11-backup.png` — резервная копия и восстановление.
14. `12-diagnostics.png` — журнал и диагностика.

## Требования

- один телефон и одинаковое разрешение;
- вертикальная ориентация;
- русский язык;
- одинаковая тема и масштаб интерфейса;
- исходный PNG без предварительного уменьшения;
- демонстрационные названия профилей и серверов;
- отсутствие приватных URL, UUID, ключей, токенов и внутренних адресов;
- отсутствие личных уведомлений в строке состояния;
- текст должен полностью помещаться на экране.

Для основной галереи используется светлая тема. Несколько ключевых экранов в тёмной теме можно добавить отдельным дополнительным набором.

## Проверка перед загрузкой

Для каждого снимка проверьте:

- правильное имя файла;
- отсутствие личных данных;
- отсутствие реальных адресов и секретов;
- отсутствие красных стрелок, зачёркиваний и служебных пометок;
- полную видимость заголовков и кнопок;
- одинаковый масштаб со всем набором;
- соответствие актуальной версии интерфейса.

Исходные PNG хранятся отдельно от публичной витрины. В репозиторий добавляются только проверенные оптимизированные копии.
