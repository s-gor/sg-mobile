# SG Mobile 080

Версия: `0.0.106-080`  
versionCode: `206`  
Android: `8.0+`  
ABI: `arm64-v8a`

## Основное

080 — это крупное обновление интерфейса и пользовательской логики поверх актуальной сетевой линии SG Mobile.

Главный экран получил новый фирменный стиль Security Group, новый щит, отдельное отображение состояния и действия VPN, компактную строку Connected / Disconnected и переработанные быстрые действия.

Профили и подписки приведены к более последовательному поведению. Отдельный профиль теперь можно обновить без дублирования, а выбор новой ноды во время активного VPN больше не откатывается на старую после остановки.

## Интерфейс

- новый фирменный щит и launcher icon;
- обновлённый splash;
- Online / Offline как состояние;
- On / Off как действие;
- компактная строка Connected / Disconnected с временем, ping и трафиком;
- стеклянная заливка статуса в тёмной и светлой темах;
- быстрые действия: QR, импорт из изображения, маршрутизация, настройки;
- отдельные значки профилей, подписок, статуса и статистики;
- более аккуратный экран статистики трафика.

## Профили и подписки

- повторный parse сохранённого source для обновления отдельного профиля;
- сохранение ID, избранного и результатов замеров;
- отсутствие дубликата при обновлении;
- независимое хранение выбранной и реально запущенной ноды;
- обновление подписок и профилей приведено к единой логике.

## Сеть

Сохранена актуальная линия Single Edge 443 и поддержка:

- VLESS
- VMess
- Trojan
- XHTTP
- Hysteria2
- AnyTLS
- TUIC
- Mieru
- NaiveProxy
- AmneziaWG 2.0
- AmneziaWG 3.0
- AmneziaWG 3.1

Mieru работает по TCP/443. AnyTLS сохраняет необходимые TLS/ALPN параметры. NaiveProxy работает через 443.

## Routing

Сохранены:
- target node;
- multi-node routing;
- балансировка доступных backend-подключений;
- priority controls;
- country picker;
- capability gate.

## Установка

APK для 080 публикуется непосредственно в репозитории, без GitHub Releases.

Перед установкой необходимо проверить SHA-256 APK. Для обновления поверх предыдущей версии package name и подпись должны совпадать.
