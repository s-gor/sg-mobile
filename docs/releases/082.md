# SG Mobile 082

Версия:
- build: **082**
- versionCode: **208**
- versionName: **0.0.108-082**
- Android: **8.0+**
- ABI: **arm64-v8a**

## Что нового после 081

### DNS

В 082 DNS разделён на отдельные роли:

- **Прямой DNS** — для запросов, которые должны идти напрямую;
- **DNS через прокси** — основной DNS внутри защищённого маршрута;
- **Загрузочный DNS** — для начального разрешения адресов, необходимых до поднятия защищённого DNS-пути.

Добавлены:

- тест скорости DNS-серверов;
- назначение найденного DNS в нужную роль;
- поддержка DNS-over-TLS;
- редактор DNS hosts;
- очистка DNS-кэша.

### IPv6

Добавлены глобальные режимы:

- **Авто**;
- **Только IPv4**;
- **IPv4 + IPv6**.

В пользовательских правилах маршрутизации можно отдельно выбрать:

- **Оба**;
- **IPv4**;
- **IPv6**.

Для режима «Только IPv4» добавлена защита от утечки IPv6.

### Пауза после выключения экрана

Можно задать паузу VPN после выключения экрана, если трафик отсутствует.

Интервалы:

- 5 минут;
- 10 минут;
- 15 минут;
- 30 минут.

Активность трафика сбрасывает таймер ожидания.

### Темы

Добавлены две темы:

- **SG Soft**;
- **Pure Black OLED**.

Pure Black использует настоящий чёрный фон и более строгую OLED-схему без избыточной фоновой подсветки.

Для VPN в Dark и Pure Black используется голубой щит. Для SOCKS сохранена бронзовая схема.

### Маршрутизация российских ресурсов

В 082 переработана часть системных правил:

- исправлена логика AND/OR для системных domain/IP условий;
- заблокированные российские ресурсы обрабатываются раньше широкого правила «Россия → напрямую»;
- добавлены отдельные исключения для 4PDA;
- при недоступных или повреждённых GeoFiles подключение не должно останавливаться;
- в таком случае используется безопасный режим «всё через VPN».

Добавлены отдельные переключатели:

- режим совместимости для MAX/VK;
- обход сервисов проверки внешнего IP.

### Импорт

Улучшен импорт:

- YAML;
- JSON;
- TXT.

Для AmneziaWG/WireGuard улучшено формирование имени профиля.

При наличии сохраняются метаданные:

- Profile;
- Access;
- Name;
- Server.

### Reality / TUN diagnostics

Расширена диагностическая информация для случаев, когда одинаковый Reality-профиль ведёт себя по-разному в разных сетях.

Добавлены данные:

- результат protect(fd);
- endpoint;
- MTU;
- используемая физическая сеть;
- диагностический режим исключения собственного процесса из TUN.

## Что сознательно не заявляется как готовая функция

В описание 082 не включены функции, пользовательский сценарий которых ещё требует отдельной проверки:

- полноценный hot switch;
- SMART поверх уже активного VPN;
- маршрутизация одного правила через несколько нод;
- балансировка нескольких нод внутри одного пользовательского правила.

Эти возможности не считаются публично заявленными функциями 082 до отдельной проверки.

## Установка

Финальный APK 082 публикуется только после полной проверки сборки.

Перед установкой проверяйте SHA-256 APK.

Для обычного обновления не удаляйте предыдущую установленную версию, если она подписана тем же ключом и использует тот же package name.
