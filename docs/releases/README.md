# Публичные релизы SG Mobile

Каждый GitHub Release должен быть самодостаточным и содержать файлы, относящиеся к одной версии.

## Обязательные материалы

- подписанный APK;
- файл `SHA256SUMS.txt`;
- номер сборки, versionCode и versionName;
- минимальную версию Android;
- поддерживаемую ABI;
- краткий список изменений;
- известные ограничения;
- указание на совместимость обновления с предыдущей подписью;
- уведомления и лицензионные материалы сторонних компонентов.

## Рекомендуемое имя APK

```text
SG-Mobile-074P-v0.0.93.apk
```

Имя должно однозначно показывать продукт и версию. Нельзя заменять опубликованный APK другим файлом под тем же именем.

## Контрольная сумма

Файл `SHA256SUMS.txt` должен содержать полную SHA-256 и точное имя APK:

```text
<64 шестнадцатеричных символа>  SG-Mobile-074P-v0.0.93.apk
```

## Порядок публикации

1. Собрать release APK.
2. Проверить unit-тесты, R8 и resource shrink.
3. Подписать APK установленным релизным ключом.
4. Установить APK поверх предыдущей версии.
5. Проверить запуск VPN и основные разделы.
6. Вычислить SHA-256 уже подписанного APK.
7. Создать GitHub Release.
8. Загрузить APK и `SHA256SUMS.txt`.
9. Проверить скачанные из Release файлы повторно.

До выполнения этих шагов сборка не должна называться публичным релизом.
