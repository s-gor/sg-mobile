# Публичные версии SG Mobile

Актуальная версия: **080**.

Описание текущей версии: [080.md](080.md).

## Что публикуется

Для публичной версии в репозитории должны быть доступны:

- подписанный APK;
- SHA-256 для APK;
- номер build, versionCode и versionName;
- минимальная версия Android;
- поддерживаемая ABI;
- краткое описание изменений;
- лицензионные материалы сторонних компонентов.

APK публикуется непосредственно в репозитории, без GitHub Releases.

- [077](077.md) — 0.0.96-smart-failover, versionCode 196
