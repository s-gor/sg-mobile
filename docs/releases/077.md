# SG Mobile 077 — SMART Failover

SG Mobile 077 — крупное обновление по сравнению с линией 075. Основной упор этого выпуска — автоматическое резервирование VPN, единая DNS-политика, маршрутизация, Per-App VPN и более строгая проверка реальной работоспособности соединения.

**Version:** `0.0.96-smart-failover`  
**versionCode:** `196`  
**Android:** `8.0+`  
**ABI:** `arm64-v8a`

> NaiveProxy в линию 077 не входит.

## SMART Failover

Главное изменение 077 — новый SMART-балансер.

Можно назначить основной VPN-профиль и до трёх резервных приоритетов. Если текущее соединение перестаёт работать, SG Mobile проверяет доступные варианты и автоматически переключается на следующий рабочий.

Одновременно активен только один VPN-профиль: SMART работает как failover, а не как параллельное распределение трафика между несколькими ядрами.

Добавлены:

- основной профиль и до трёх резервных приоритетов;
- готовые сценарии для домашней, мобильной и нестабильной сети;
- режим для более строгих блокировок;
- режим без автоматического возврата;
- cooldown для отказавших профилей;
- ограничение количества переключений;
- запоминание последнего рабочего профиля;
- автоматический возврат на основной профиль;
- выбор резерва по профилю, протоколу, избранному, подписке или любому доступному узлу.

## Проверка реальной работы VPN

В 077 состояние «ядро запустилось» больше не считается достаточным доказательством рабочего VPN.

Клиент использует состояние runtime, DNS/HTTPS-проверки и дополнительные признаки доступности сети. SMART сочетает пассивное наблюдение с активными проверками при признаках проблемы и через контрольные интервалы.

Во время автоматического переключения используется blocking TUN, чтобы трафик не уходил мимо VPN.

## Routing и блокировка рекламы

Маршрутизация стала общей частью VPN-архитектуры SG Mobile.

Поддерживаются:

- VPN / Direct / Block;
- пользовательские правила;
- RU White List;
- RU Blocked;
- GeoFiles;
- отдельная политика для локальной сети;
- блокировка рекламы и трекеров на базе Xray routing.

Для AmneziaWG добавлен routed-путь через локальный SOCKS bridge и Xray routing. Это позволяет применять правила маршрутизации и Ads к AWG-профилям.

Поддерживается семейство:

- AWG 2.0;
- AWG 3.0;
- AWG 3.1.

## Единая DNS-политика

В 077 введена единая DNS policy вместо отдельных несвязанных настроек разных runtime.

Доступны:

- SG Auto;
- Cloudflare;
- Google;
- AdGuard;
- Quad9;
- System DNS;
- собственный IPv4/IPv6 DNS;
- Custom DoH.

Bootstrap-разрешение адресов VPN-серверов отделено от пользовательского туннеля, а исходные hostname/SNI сохраняются там, где это требуется протоколом.

Для SG Mieru используется специальный TCP DNS path через тот же локальный SOCKS, без зависимости от SOCKS UDP ASSOCIATE.

## Per-App VPN

Можно выбрать, какие Android-приложения используют VPN:

- весь трафик устройства;
- только выбранные приложения;
- исключить выбранные приложения из VPN.

Для AmneziaWG исправлена проверка рабочего соединения в режиме «Только выбранные», включая AWG 2.0, 3.0 и 3.1.

## Поддерживаемые протоколы

В линии 077 поддерживаются:

- VLESS;
- VMess;
- Trojan;
- Hysteria2;
- Mieru;
- AnyTLS;
- TUIC;
- AWG 2.0;
- AWG 3.0;
- AWG 3.1.

**NaiveProxy не входит в SG Mobile 077.**

## Стабильность и управление соединением

В 077 также сохранены и развиты механизмы восстановления соединения:

- reconnect после проблем с сетью;
- корректная работа при переключении Wi‑Fi / LTE / 5G;
- защита от параллельных connect/disconnect;
- Quick Settings Tile;
- управление соединением из уведомления;
- отображение реально активного VPN-профиля;
- защита от stale-профилей подписки;
- ручной и автоматический MTU.

## Что изменилось относительно 075

**075** — ручной VPN-клиент с быстрым ping, мониторингом трафика и выбором сервера.

**077** — более автономный VPN-клиент с SMART Failover, unified DNS, Per-App VPN, routed AmneziaWG, расширенной маршрутизацией и более строгим контролем реальной работоспособности соединения.
