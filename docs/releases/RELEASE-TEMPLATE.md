## Проверка APK

SHA-256:

```text
[ПОЛНЫЙ SHA-256]  SG-Mobile-[ВЕРСИЯ]-arm64-v8a.apk
```

Windows PowerShell:

```powershell
Get-FileHash .\SG-Mobile-[ВЕРСИЯ]-arm64-v8a.apk -Algorithm SHA256
```

Linux:

```bash
sha256sum SG-Mobile-[ВЕРСИЯ]-arm64-v8a.apk
```

macOS:

```bash
shasum -a 256 SG-Mobile-[ВЕРСИЯ]-arm64-v8a.apk
```

Совпасть должна вся строка SHA-256.

## Установка

1. Скачайте APK и `SHA256SUMS.txt` из этого релиза.
2. Проверьте SHA-256.
3. Разрешите установку APK из выбранного источника Android.
4. Установите приложение.
5. При обновлении поверх предыдущей официальной версии пользовательские данные должны сохраниться.
6. После запуска проверьте номер версии в разделе «О приложении».

## Перед обновлением

Перед тестовой или крупной версией рекомендуется создать резервную копию через боковое меню → «Резервная копия».
