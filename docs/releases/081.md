# SG Mobile 081

Версия: `0.0.107-081`  
versionCode: `207`  
Android: `8.0+`  
ABI: `arm64-v8a`

## Основное

081 развивает интерфейс и повседневную работу SG Mobile после 080: отдельные режимы PROXY/VPN и SOCKS, компактные профили, обновлённая витрина быстрых действий, автоматическая обработка подписок после обновления и новый алгоритм определения флага страны.

## Главный экран

- отдельные режимы **SOCKS** и **PROXY / VPN**;
- собственные пиктограммы режимов;
- пять быстрых действий в одном ряду:
  - Scan QR;
  - From Image;
  - Routing;
  - Apps;
  - Refresh;
- SMART-балансер оставлен отдельным крупным элементом;
- убрано дублирование глобальных настроек на витрине.

## SOCKS

- локальный SOCKS5 без Android VPN/TUN;
- адрес по умолчанию: `127.0.0.1:10808`;
- подсказка при первом запуске;
- пример настройки Telegram;
- возможность больше не показывать подсказку.

## Профили

- более компактная карточка и экран деталей;
- переработано расположение QR / LINK / CONFIG / Copy / Share / Latency / URL-test;
- исправлено положение ACTIVE;
- сервер и порт разведены в редакторе;
- длинный редактор профиля получил нормальный вертикальный scroll;
- устранено обрезание нижних полей;
- уменьшено количество одинаковых шестерёнок и переработаны иконки действий.

## Подписки

После обновления подписки выполняется безопасная автоматическая обработка:
- latency probe поддерживаемых профилей;
- доступные профили сортируются по задержке;
- неответившие перемещаются вниз;
- профили без безопасного probe пропускаются без запуска VPN runtime.

Быстрая кнопка Refresh на главной предлагает:
- **Все подписки**;
- **Выбрать подписку**;
- **Только активную**.

При массовом обновлении показывается прогресс по источникам.

## Флаг страны

Новый алгоритм определения страны ноды:

**Авто | Домен | Сервер**

- **Авто** — автоматический выбор источника;
- **Домен** — определение по TLD (`.uk → GB`, `.pl → PL` и т. п.);
- **Сервер** — GeoIP реального IP ноды.

Для локального профиля доступен ручной override страны; ручное значение имеет приоритет.

## Per-App VPN

Сохранены режимы:
- все приложения;
- только выбранные;
- исключить выбранные.

SOCKS и Per-App VPN остаются разными механизмами.

## SMART

Сохранён существующий SMART failover:
- failure threshold;
- cooldown;
- резервные профили;
- автоматические попытки переключения;
- лимит переключений;
- возврат на основной профиль по сценарию.

## UI polish

- исправлены отступы и переполнения;
- исправлено обрезание URL-test;
- улучшено размещение элементов на экранах небольшой высоты;
- иконки быстрых действий приведены к более понятным ролям;
- редактор профиля больше не показывает обрезанный нижний элемент.
