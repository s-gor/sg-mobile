# SG Mobile 082

SG Mobile 082 — следующая публичная версия Android-клиента Security Group.

Версия приложения:
- build: 082
- versionCode: 208
- versionName: 0.0.108-082
- Android: 8.0 и новее
- архитектура: arm64-v8a

> APK 082 будет опубликован после финальной проверки сборки. До этого не удаляйте установленную рабочую версию ради тестовой сборки.

## Что изменилось после 081

### DNS

Добавлены отдельные роли:
- **Прямой DNS**;
- **DNS через прокси**;
- **Загрузочный DNS**.

Также добавлены:
- тест скорости DNS-серверов;
- назначение результата теста сразу в нужную DNS-роль;
- DNS-over-TLS;
- редактор DNS hosts;
- очистка DNS-кэша.

### IPv6

Добавлены глобальные режимы:
- **Авто**;
- **Только IPv4**;
- **IPv4 + IPv6**.

В пользовательских правилах маршрутизации добавлен выбор:
- **Оба**;
- **IPv4**;
- **IPv6**.

Для режима «Только IPv4» добавлена защита от утечки IPv6.

### Экран и питание

Добавлена пауза VPN после выключения экрана при отсутствии трафика.

Доступные интервалы:
- 5 минут;
- 10 минут;
- 15 минут;
- 30 минут.

### Темы

Добавлены:
- **SG Soft**;
- **Pure Black OLED**.

Pure Black использует настоящий чёрный фон и более спокойную систему акцентов.

В Dark и Pure Black для VPN используется голубой щит вместо зелёного. SOCKS сохраняет бронзовую цветовую схему.

### Маршрутизация

Переработана обработка российских ресурсов:
- исправлена логика AND/OR в системных правилах;
- заблокированные российские ресурсы обрабатываются раньше широкого правила «Россия → напрямую»;
- добавлены отдельные исключения для 4PDA;
- при недоступных или повреждённых GeoFiles подключение не должно останавливаться: используется безопасный режим «всё через VPN».

Также добавлены:
- отдельный режим совместимости для MAX/VK;
- отдельный обход сервисов проверки внешнего IP.

### Импорт

- улучшен импорт YAML / JSON / TXT;
- улучшено именование импортируемых AmneziaWG/WireGuard-профилей;
- при наличии сохраняются поля Profile, Access, Name и Server.

### Reality / TUN

Расширена диагностика сложных случаев Reality/TUN:
- protect(fd);
- endpoint;
- MTU;
- используемая сеть;
- диагностика исключения собственного процесса из TUN.

## Установка

APK публикуется непосредственно в этом репозитории, без GitHub Releases.

Перед установкой проверяйте SHA-256 опубликованного APK. Для обычного обновления не удаляйте установленное приложение: Android сохранит данные только при установке поверх версии с тем же package name и подписью.
