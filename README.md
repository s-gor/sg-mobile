# SG Mobile 079J

SG Mobile 079J — актуальная тестовая версия Android-клиента.

Версия приложения:
- versionCode: 204
- versionName: 0.0.104-079j
- Android: 8.0 и новее
- Архитектура: arm64-v8a

## Что сделано в 079J

### Mieru

Mieru переведён на единый внешний порт 443 по TCP.

Исправлена обработка старых профилей, которые могли сохранять прежний порт 2099 или старый transport. Теперь SG-профили Mieru используют актуальную схему подключения и не зависят от устаревших параметров, оставшихся в сохранённой ссылке.

Исправлен локальный DNS-путь Mieru через Xray. Убрана несовместимость с новым Xray, из-за которой подключение могло завершаться ещё до выхода к серверу.

Работа Mieru подтверждена на реальном Android-устройстве.

### AnyTLS

Сохранена и закреплена работа AnyTLS через Single Edge на порту 443.

SG Mobile сохраняет необходимые параметры TLS и ALPN для подключения через общий внешний вход.

### NaiveProxy

NaiveProxy добавлен в актуальную линию SG Mobile.

Подключение работает через порт 443. Имя сервера сохраняется для TLS, а адрес назначения может быть предварительно разрешён через SG bootstrap DNS.

Добавлены проверки, чтобы этот режим не возвращался к старой схеме подключения.

### Routing

Маршрутизация расширена для работы не только с текущим подключением, но и с выбранными нодами.

Теперь правило может направлять трафик:
- через текущую ноду;
- через одну выбранную ноду;
- через несколько выбранных нод.

Для нескольких нод используется балансировка между доступными backend-подключениями.

Добавлены:
- выбор целевой ноды;
- выбор нескольких нод;
- управление приоритетом правил;
- выбор страны;
- проверка совместимости правила до его сохранения.

Неподдерживаемые комбинации больше не принимаются молча.

### AmneziaWG

Исправлен импорт однострочных конфигураций AmneziaWG.

Раньше SG Mobile мог сообщать об отсутствии PrivateKey, даже если ключ присутствовал в конфигурации, но весь профиль был передан одной строкой.

Теперь такие конфигурации корректно разбираются на Interface и Peer и сохраняют необходимые параметры AWG 2.0, AWG 3.0 и AWG 3.1.

Исправление подтверждено на реальном профиле.

### Профили и подписки

Сохранена поддержка отдельных профилей и подписок с несколькими протоколами.

Продолжает работать защита от устаревших и удалённых серверных профилей, а также обновление сохранённых параметров подключения при получении актуальной конфигурации.

### Стабильность подключения

Сохранены механизмы:
- восстановления после смены сети;
- защиты от параллельных connect/disconnect;
- автоматического и ручного MTU;
- контроля реального состояния VPN;
- работы через Wi‑Fi, LTE и 5G;
- блокировки утечек при переключениях.

## Статус 079J

В 079J подтверждена работа Mieru и исправлен импорт AmneziaWG.

Остальные изменения этой линии включают обновлённый Routing, Single Edge для поддерживаемых протоколов и подготовку клиента к дальнейшей интеграции с SG-Net.

Публичный APK следует считать выпущенным только после появления отдельного GitHub Release с APK и контрольной суммой SHA-256.
