# SG Mobile 081

SG Mobile 081 — следующая публичная версия Android-клиента Security Group.

Версия приложения:
- build: 081
- versionCode: 207
- versionName: 0.0.107-081
- Android: 8.0 и новее
- архитектура: arm64-v8a

> APK 081 будет опубликован после финальной проверки сборки. До этого актуальный публичный APK в репозитории остаётся 080.

## Что изменилось после 080

### Главный экран

Главная витрина переработана под два понятных режима работы:
- **PROXY / VPN** — обычное VPN-подключение;
- **SOCKS** — локальный SOCKS5 для приложений, которые умеют использовать прокси вручную.

Режимы получили отдельные фирменные пиктограммы и визуальное состояние.

Блок быстрых действий расширен до пяти кнопок:
- Scan QR;
- импорт QR из изображения;
- Routing;
- Apps;
- Refresh subscriptions.

SMART-балансер сохранён отдельной крупной кнопкой под быстрыми действиями.

### SOCKS

SOCKS оставлен именно локальным SOCKS5, без подмены его Android VPN/TUN-механизмом.

Адрес по умолчанию:
`127.0.0.1:10808`

При первом использовании SG Mobile объясняет, что SOCKS должен быть настроен внутри самого приложения. Встроен пример для Telegram, а подсказку можно отключить.

### Профили

Карточка и детали профиля стали компактнее.

Переработаны:
- QR;
- LINK / CONFIG;
- Copy;
- Share;
- Latency;
- URL-test;
- расположение ACTIVE.

В редакторе профиля:
- сервер занимает полную ширину;
- порт вынесен отдельно;
- расширенные параметры собраны аккуратнее;
- длинная форма нормально прокручивается;
- устранено обрезание нижних полей и визуальная «тонкая полоска».

Также убрано лишнее дублирование шестерёнок: иконки теперь различаются по назначению.

### Подписки

После обновления подписки SG Mobile автоматически выполняет безопасный latency-тест поддерживаемых профилей и сортирует их:
- доступные и более быстрые — выше;
- неответившие — ниже;
- профили, для которых безопасный probe не применяется, не ломаются диагностикой.

На главном экране кнопка Refresh теперь спрашивает, что обновить:
- **Все подписки**;
- **Выбрать подписку**;
- **Только активную**.

Во время обновления отображается состояние процесса и прогресс по подпискам.

### Новый алгоритм флага страны

Добавлен отдельный режим определения страны ноды:

**Авто | Домен | Сервер**

- **Авто** — SG Mobile выбирает подходящий источник;
- **Домен** — страна определяется по доменной зоне, например `.uk → GB`, `.pl → PL`;
- **Сервер** — страна определяется по реальному IP ноды через GeoIP.

Для отдельного локального профиля можно вручную задать код страны. Ручной выбор имеет приоритет над автоматическим определением.

### Per-App VPN

Сохранены три понятных режима:
- все приложения через VPN;
- только выбранные;
- все, кроме выбранных.

Per-App VPN не смешивается с локальным SOCKS.

### SMART

SMART-балансер по-прежнему отвечает за автоматический failover:
- контроль активной ноды;
- порог последовательных ошибок;
- cooldown проблемного профиля;
- переход на резерв;
- повторные попытки;
- лимит переключений;
- возврат на основной профиль, если это предусмотрено сценарием.

### Интерфейс

В 081 продолжена общая полировка:
- исправлены отступы и переполнения;
- уменьшено визуальное дублирование элементов;
- исправлено обрезание URL-test;
- улучшена работа экранов на небольшой высоте;
- быстрые действия и иконки приведены к более понятной логике.

## Установка

APK публикуется непосредственно в этом репозитории, без GitHub Releases.

Перед установкой проверяйте SHA-256 опубликованного APK. Для обычного обновления не удаляйте установленное приложение: Android сохранит данные только при установке поверх версии с тем же package name и подписью.
