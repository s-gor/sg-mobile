# SG Mobile 080

SG Mobile 080 — актуальная публичная версия Android-клиента Security Group.

Версия приложения:
- build: 080
- versionCode: 206
- versionName: 0.0.106-080
- Android: 8.0 и новее
- архитектура: arm64-v8a

## Что изменилось в 080

### Новый интерфейс и фирменный стиль

SG Mobile получил новое оформление: фирменный щит, обновлённый главный экран, более компактные статусы подключения и единый визуальный стиль для тёмной и светлой темы.

На главном экране состояние VPN теперь отделено от действия:
- Online / Offline показывает текущее состояние;
- On / Off управляет подключением;
- отдельная строка состояния показывает Connected / Disconnected, время сессии, задержку и трафик.

Быстрые действия на главной переработаны: сохранены QR и импорт из изображения, добавлены быстрые переходы в маршрутизацию и настройки.

### Профили

Обновление отдельного профиля теперь повторно разбирает сохранённую исходную ссылку или конфигурацию текущим parser-ом без создания дубликата.

При обновлении сохраняются:
- ID профиля;
- избранное;
- результаты замеров;
- пользовательский выбор.

Выбор профиля во время активного VPN отделён от реально запущенной ноды: новый выбор сразу подсвечивается и не откатывается после остановки VPN.

### Подписки

Интерфейс профилей и подписок приведён к единой логике. Обновление вынесено в верхнюю панель, а действия проверки и сортировки получили отдельное пространство.

Для подписок используется отдельный значок с двумя силуэтами, чтобы он не путался с обновлением.

### Статистика и статус

Экран статистики трафика очищен от лишней второй шапки.

Статус и статистика получили разные значки. Убраны малополезные проценты доли трафика из карточек. Тексты и подписи приведены к русскому интерфейсу.

### Single Edge и протоколы

Сохранена работа Single Edge на внешнем порту 443 для поддерживаемых протоколов.

В актуальной линии поддерживаются:
- VLESS
- VMess
- Trojan
- XHTTP
- Hysteria2
- AnyTLS
- TUIC
- Mieru
- NaiveProxy
- AmneziaWG 2.0
- AmneziaWG 3.0
- AmneziaWG 3.1

Mieru использует актуальную схему TCP/443. AnyTLS сохраняет необходимые TLS/ALPN параметры. NaiveProxy работает через 443.

### Маршрутизация

Сохранена расширенная маршрутизация с выбором одной или нескольких целевых нод, приоритетами правил, выбором страны и проверкой совместимости до сохранения.

### Стабильность

Сохранены:
- восстановление после смены Wi-Fi / LTE / 5G;
- защита от параллельных connect/disconnect;
- автоматический и ручной MTU;
- контроль реального состояния VPN;
- Per-App VPN;
- защита от утечек;
- SMART failover;
- локальная диагностика и статистика.

## Установка

APK публикуется непосредственно в этом репозитории, без GitHub Releases.

Перед установкой проверяйте SHA-256 опубликованного APK. Для обычного обновления не удаляйте установленное приложение: Android сохранит данные только при установке поверх версии с тем же package name и подписью.
