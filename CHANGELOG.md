# История изменений SG Mobile

## 082 — 0.0.108-082, versionCode 208

### DNS

- добавлены отдельные роли: **Прямой DNS / DNS через прокси / Загрузочный DNS**;
- добавлен тест скорости DNS-серверов;
- результат теста можно сразу назначить в нужную DNS-роль;
- добавлена поддержка DNS-over-TLS;
- добавлен редактор DNS hosts;
- добавлена очистка DNS-кэша.

### IPv6

- добавлены глобальные режимы **Авто / Только IPv4 / IPv4 + IPv6**;
- в пользовательских правилах маршрутизации добавлен выбор **Оба / IPv4 / IPv6**;
- для режима «Только IPv4» добавлена защита от утечки IPv6.

### Экран и питание

- добавлена пауза VPN после выключения экрана при отсутствии трафика;
- доступны интервалы 5, 10, 15 и 30 минут.

### Темы

- добавлена тема **SG Soft**;
- добавлена OLED-тема **Pure Black**;
- Pure Black использует настоящий чёрный фон и более спокойную систему акцентов;
- для VPN в Dark и Pure Black используется голубой щит вместо зелёного;
- SOCKS сохраняет бронзовую цветовую схему.

### Маршрутизация

- переработана обработка российских ресурсов;
- исправлена логика AND/OR в системных правилах;
- заблокированные российские ресурсы обрабатываются раньше широкого правила «Россия → напрямую»;
- добавлены отдельные исключения для 4PDA;
- при недоступных или повреждённых GeoFiles подключение не должно останавливаться: используется безопасный режим «всё через VPN»;
- добавлен отдельный режим совместимости для MAX/VK;
- добавлен отдельный обход сервисов проверки внешнего IP.

### Импорт

- улучшен импорт YAML / JSON / TXT;
- улучшено именование импортируемых AmneziaWG/WireGuard-профилей;
- при наличии сохраняются поля Profile, Access, Name и Server.

### Reality / TUN

- расширена диагностическая информация для сложных случаев Reality/TUN;
- добавлены данные по protect(fd), endpoint, MTU и используемой сети;
- добавлена диагностика исключения собственного процесса из TUN.

### Ядра

- Xray / libXray: `26.9.30`;
- Mieru: `3.38.0`;
- Mihomo: `1.19.32`;
- Hysteria2: `2.12.3`;
- sing-box: `1.14.1`;
- AmneziaWG: ветка `20260828`.

### Сборка

- build: `082`;
- versionCode: `208`;
- versionName: `0.0.108-082`;
- Android: `8.0+`;
- ABI: `arm64-v8a`.

Полное описание: [docs/releases/082.md](docs/releases/082.md).

## 081 — 0.0.107-081, versionCode 207

### Главный экран

- добавлены отдельные режимы SOCKS и PROXY / VPN;
- режимы получили собственные пиктограммы;
- быстрые действия расширены до пяти: Scan QR, From Image, Routing, Apps, Refresh;
- SMART-балансер сохранён отдельной крупной кнопкой;
- убрано лишнее дублирование глобальных настроек на витрине.

### SOCKS

- SOCKS оставлен локальным SOCKS5 без Android VPN/TUN;
- адрес по умолчанию: `127.0.0.1:10808`;
- добавлена подсказка первого запуска;
- добавлен пример настройки Telegram;
- подсказку можно отключить.

### Профили

- карточка и детали профиля стали компактнее;
- переработано расположение QR, LINK / CONFIG, Copy, Share, Latency и URL-test;
- исправлено положение ACTIVE;
- сервер и порт разведены в редакторе;
- форма редактирования получила нормальную вертикальную прокрутку;
- устранено обрезание нижних полей;
- уменьшено количество одинаковых шестерёнок и переработаны иконки действий.

### Подписки

- после обновления выполняется безопасный latency probe поддерживаемых профилей;
- доступные профили сортируются по задержке;
- неответившие перемещаются вниз;
- профили без безопасного probe пропускаются без запуска VPN runtime;
- Refresh на главной предлагает обновить все подписки, выбрать одну или обновить только активную;
- при массовом обновлении отображается прогресс.

### Флаг страны

- добавлены режимы **Авто / Домен / Сервер**;
- режим Домен определяет страну по TLD;
- режим Сервер использует GeoIP реального IP ноды;
- для локального профиля доступен ручной override страны;
- ручной выбор имеет приоритет над автоматикой.

### Per-App VPN и SMART

- сохранены режимы «Все приложения», «Только выбранные», «Исключить выбранные»;
- SOCKS и Per-App VPN остаются независимыми механизмами;
- сохранён SMART failover с failure threshold, cooldown, резервами, лимитом переключений и возвратом на основной профиль.

### UI polish

- исправлены отступы и переполнения;
- исправлено обрезание URL-test;
- улучшена работа экранов небольшой высоты;
- устранён визуальный артефакт в редакторе профиля;
- быстрые действия и иконки приведены к более понятной логике.

### Сборка

- build: `081`;
- versionCode: `207`;
- versionName: `0.0.107-081`;
- Android: `8.0+`;
- ABI: `arm64-v8a`.

Полное описание: [docs/releases/081.md](docs/releases/081.md).

## 077 — 0.0.96-smart-failover, versionCode 196

### SMART Failover

- добавлен SMART-балансер с основным профилем и до трёх резервных приоритетов;
- добавлены готовые сценарии для домашней, мобильной и нестабильной сети;
- добавлены cooldown отказавших профилей, лимит переключений и запоминание последнего рабочего профиля;
- добавлен автоматический возврат на основной профиль для соответствующих сценариев;
- резерв можно выбирать по профилю, протоколу, избранному, подписке или любому доступному узлу;
- одновременно работает только один VPN-профиль: SMART является failover, а не балансировкой нескольких туннелей.

### Проверка соединения

- состояние «runtime запущен» отделено от состояния «VPN реально работает»;
- используются DNS/HTTPS-проверки и дополнительные признаки доступности сети;
- активные проверки выполняются при признаках проблемы и через контрольные интервалы;
- во время автоматического переключения используется blocking TUN.

### DNS

- введена единая DNS policy для разных VPN runtime;
- добавлены SG Auto, Cloudflare, Google, AdGuard, Quad9 и System DNS;
- поддерживаются собственные IPv4/IPv6 DNS и Custom DoH;
- bootstrap-разрешение адресов VPN-серверов отделено от пользовательского туннеля;
- для SG Mieru используется TCP DNS path через локальный SOCKS.

### Routing и Ads

- сохранены VPN / Direct / Block, пользовательские правила, RU White List, RU Blocked и GeoFiles;
- расширена блокировка рекламы и трекеров;
- для AmneziaWG добавлен routed-путь через локальный SOCKS bridge и Xray routing;
- Routing и Ads могут применяться к AWG 2.0, AWG 3.0 и AWG 3.1.

### Per-App VPN

- сохранены режимы «весь трафик», «только выбранные приложения» и «исключить выбранные»;
- исправлена проверка AmneziaWG в режиме «Только выбранные».

### Стабильность

- сохранены reconnect после проблем с сетью и восстановление после Wi‑Fi / LTE / 5G;
- сохранена защита от параллельных connect/disconnect;
- сохранены Quick Settings Tile и управление соединением из уведомления;
- улучшено отображение реально активного VPN-профиля;
- сохранены stale-subscription guard и ручной/автоматический MTU.

### Протоколы

Линия 077 включает VLESS, VMess, Trojan, Hysteria2, Mieru, AnyTLS, TUIC, AWG 2.0, AWG 3.0 и AWG 3.1.

**NaiveProxy в линию 077 не входит.**

- versionName: `0.0.96-smart-failover`;
- целевая ABI: `arm64-v8a`;
- минимальная версия Android: `8.0`.

Полное описание: [docs/releases/077.md](docs/releases/077.md).
